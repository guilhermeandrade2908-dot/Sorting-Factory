## Português

### 📖 Sobre o Projeto
Este repositório foi desenvolvido com fins estritamente **didáticos e acadêmicos** para centralizar o estudo, análise e implementação dos principais algoritmos de ordenação da ciência da computação. 

O projeto foi inteiramente construído utilizando a pseudolinguagem **Portugol** (através do ecossistema do Portugol Studio). Ele funciona como uma excelente base de lógica estruturada e análise de algoritmos antes da transição e portabilidade para linguagens comerciais e de produção.

### 📊 Algoritmos Implementados & Complexidade
O programa executa de forma centralizada e permite analisar o comportamento dos seguintes métodos:

| Algoritmo | Melhor Caso | Caso Médio | Pior Caso |
| :--- | :---: | :---: | :---: |
| **Bubble Sort** | O(n) | O(n²) | O(n²) |
| **Selection Sort** | O(n²) | O(n²) | O(n²) |
| **Insertion Sort** | O(n) | O(n²) | O(n²) |
| **Quick Sort** | O(n log n) | O(n log n) | O(n²) |
| **Merge Sort** | O(n log n) | O(n log n) | O(n log n) |
| **Heap Sort** | O(n log n) | O(n log n) | O(n log n) |
